## 📌 About

**Doc-converter** is a lightweight, open-source web application that converts common document formats into **PDF files**.  
Built with simplicity and speed in mind, it requires no registration and runs entirely in your browser (or with a lightweight Python backend).

> ✨ *It is a small software that can convert files into PDF.*

---

## 🚀 Features

- ✅ **Convert multiple file types** to PDF (e.g., .docx, .txt, .odt — *expand based on actual support*)
- 🖥️ **Clean, responsive user interface** — works on desktop and mobile
- ⚡ **Fast conversion** with real-time progress feedback
- 🔒 **Privacy first** — no files are uploaded to any server (client-side processing where possible)
- 🐍 **Optional Python backend** for advanced conversions
- 🎨 **Modern UI** built with HTML5, CSS3, and JavaScript
